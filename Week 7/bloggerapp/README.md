# Blogger App — Exercise 12

This React application demonstrates multiple conditional rendering techniques and the use of list components with `map()` and `key` props.

## Components
- `BookDetails` renders a list of books.
- `BlogDetails` renders a list of blog posts.
- `CourseDetails` renders course information in a table.

## Run
```bash
cd "Week 7/bloggerapp"
npm install
npm start
```
